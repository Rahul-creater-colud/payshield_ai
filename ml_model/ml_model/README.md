# PayShield model training

## Data provenance and limitations

`dataset/transactions.csv` is generated by `create_dataset.py`. Its `is_fraud`
labels are sampled from a hand-authored risk formula. They are synthetic labels,
not adjudicated UPI fraud outcomes or a public real-world dataset. No external
dataset source or real-world model accuracy is claimed. The model is an
experimental hackathon demonstration and must not be used to approve, reject,
or block payments.

## Reproduce training

From the repository root in PowerShell:

```powershell
python ml_model\ml_model\create_dataset.py
python ml_model\ml_model\train_pipeline.py
```

The first command deliberately generates synthetic formula-based labels and
overwrites `dataset/transactions.csv`. Skip it when using a separately sourced,
properly labeled dataset that matches the documented feature schema.

The script validates the input schema, removes duplicate rows, reports missing
features, performs stratified train/validation/holdout splitting, compares
balanced Logistic Regression and Random Forest pipelines, and fits median
imputation within each training pipeline. The selected model and probability
threshold come from validation data. The untouched holdout is used only for
final evaluation.

Artifacts are written to `artifacts/`:

- `best_model.joblib` — trusted local sklearn pipeline and its feature/data
  provenance metadata.
- `best_threshold.joblib` — threshold selected using validation F1.
- `evaluation.json` — dataset hash, split sizes, candidate comparison,
  threshold, holdout metrics, and an explicit synthetic-label limitation.
- `dataset_splits/` — the reproducible train, validation, and holdout CSVs.

The backend loads the package and threshold from this directory. `joblib`
artifacts are Python pickle data: load only trusted local files and never accept
model artifacts uploaded by users.

## Current generated-dataset evaluation

The current 10,000-row dataset has 8,619 negative and 1,381 generated-positive
labels. The selected balanced Random Forest's stratified 2,000-row holdout
result at threshold `0.3382` is:

| Metric | Holdout result |
|---|---:|
| Precision | 0.3636 |
| Recall | 0.4928 |
| F1 | 0.4185 |
| PR-AUC (average precision) | 0.3249 |
| Confusion matrix (`not_fraud`, `synthetic_fraud`) | `[[1486, 238], [140, 136]]` |

These values are reproducible statistics about agreement with synthetic
generated labels only. They are not real-world accuracy, calibration, or
evidence of fraud detection effectiveness.
